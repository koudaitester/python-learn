# 人居环境评估知识库（可直接导入Dify，Markdown格式）
> 用途：接收视觉识别输出（物体、温湿度、设备状态），匹配规则，输出环境风险、整改建议；规则采用短句、条目化，便于向量检索命中。
> 分类：【温湿度基准规则】【室内物体与场景风险规则】【各类设备运行/摆放规则】【DIY水循环加湿装置专项规则】【霉菌判定标准】【人体舒适区间】

## 一、温湿度基准规则
1. 相对湿度RH＜40%：空气偏干燥；容易引发鼻腔、咽喉干痒，呼吸道敏感；**无霉菌滋生风险**。
2. 相对湿度RH 45%～55%：人体舒适区间，呼吸道友好，霉菌生长被抑制。
3. 相对湿度RH 55%～60%：临界区间，需关注局部积水、密闭死角。
4. 相对湿度RH＞60%：高湿环境，霉菌、微生物滋生风险上升。
5. 温度20℃～24℃：室内舒适温度。
6. 温度＞26℃：高温会加速霉菌繁殖；温度＜18℃，人体体感偏冷。

## 二、霉菌判定标准（核心修正，用于纠正模型误判）
1. 霉菌生长必要条件：**持续相对湿度＞60% + 存在积水/潮湿表面 + 密闭不通风死角**。
2. 仅整体环境RH＜40%，即使地面有水盆，**不会产生霉菌风险**。
3. 局部潮湿（容器内壁、滤材、窗帘边角），即使整体湿度合格，依然存在局部长菌风险。
4. 白色窗帘：干燥状态无风险；长期沾水、持续潮湿，窗帘纤维会滋生霉菌。

## 三、室内物体与场景风险规则
1. 密闭关闭窗户：室内空气流通差；
    - 室外更干燥时，关窗利于维持室内湿度，适合加湿场景；
    - 室外高湿时，长期关窗会蓄积湿气，提升发霉风险。
2. 开窗通风：短时通风用于换气；**室外空气干燥时，长时间开窗会降低室内湿度**。
3. 地面放置水盆/储水容器：
    - 用途：可用于蒸发加湿；
    - 风险点：水体长期静置不更换、容器内壁未定期清洗，会滋生细菌、微生物。
4. 家具：无积水、干燥表面，无霉菌风险；家具紧贴墙面、后方不透风，容易形成潮湿死角。
5. 通风口：存在通风口可以持续交换空气，降低局部高湿风险；无通风口只能依靠窗户换气。

## 四、成品设备运行/摆放规则
1. 加湿器（成品）：
    - 未开启：不改变室内湿度；
    - 开启状态：提升环境湿度；必须定期换水、清洗水箱，防止水箱滋生微生物；
    - 摆放：远离墙体、布艺家具，避免水雾直接打湿墙面布料。
2. 空气净化器：
    - 作用：过滤空气中粉尘、微生物；**不改变温湿度**；
    - 摆放：不要紧贴墙角，预留进风空间。
3. 空调：
    - 制冷模式：降低温度，同时降低室内湿度；
    - 制热模式：升高温度，会降低相对湿度，加剧干燥；
    - 除湿模式：专门降低室内湿度，抑制霉菌。

## 五、DIY水循环加湿装置专项规则（重点，咱们自制方案）
1. 组成：水族小水泵 + 储水盒 + 滤格/滤板 + PP棉
2. 工作原理：水泵循环水流持续浸润滤材，增大水与空气接触面积，自然蒸发加湿。
3. 水体要求：优先除氯、阻垢处理后的水；禁止长期存放不换水。
4. 消毒维护：初次使用容器、滤材需要彻底清洗；可用84消毒后，多次清水冲净，残留消毒液会挥发刺激呼吸道。
5. 减震降噪：水泵底部垫泡沫/PP棉，削弱震动传导，降低运行噪音。
6. 风险项：
    - 滤材长期不清洗，滤材附着生物膜、滋生细菌；
    - 水位过高，水溅出造成地面积水；
    - 密闭房间长时间运行，湿度持续超过60%，触发霉菌风险。
7. 控制目标：运行期间，维持室内RH 45~55%，湿度超过55%可暂停装置。

## 六、评估输出固定逻辑（给大模型的检索后推理规则）
1. 先读取输入参数：温度、相对湿度、识别到的物体清单、设备启停状态。
2. 检索知识库匹配对应规则，**禁止编造不在知识库内的结论**。
3. 风险分级：无风险、低风险、高风险。
4. 输出结构：环境概况 → 风险点 → 整改/优化建议。
5. 建议必须区分场景：如果目标是改善干燥、缓解呼吸道不适，方案优先考虑加湿；如果目标是防霉，则优先控湿、通风。
6. 提示：所有通风操作，需要参考室外温湿度条件，不能无条件建议开窗。
