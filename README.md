# README.md
## 人居微环境视觉检测系统
> 本地AI视觉检测项目，基于 Ollama + LLaVA + FastAPI，配套本地RAG知识库，用于室内/封闭空间环境识别、风险判断。

### ✨ 项目简介
本系统实现**图像上传 + 视觉大模型分析 + 场景知识库检索**，自动识别封闭人居环境参数、潜在风险，给出评估和整改建议。
- 后端：FastAPI 提供接口服务，调用本地 Ollama LLaVA 多模态模型做图像理解
- 知识库：本地 Markdown 场景规则库，轻量语义检索匹配场景，减少大模型幻觉，加速响应
- 前端：页面上传图片，调用后端接口获取环境检测结果
- 目标：快速评估密闭空间（地下舱、封闭人居舱、室内环境）温湿度、结构、空气相关风险

### 📦 核心组件
1. Ollama：本地运行 `llama3.2-vision`（LLaVA系列多模态模型），负责看图分析
2. FastAPI：后端HTTP接口，接收图片、调用模型、对接本地知识库检索
3. 本地RAG（轻量版）：读取场景MD知识库文件，做语义匹配，提取相关规则注入prompt
4. 前端页面：图像采集、请求接口、展示检测结论

### 🚀 运行流程
1. 前端上传环境图片
2. FastAPI接收图片，执行本地知识库检索，匹配相关环境场景规则
3. 将图片+检索到的场景规则，一并送入LLaVA模型
4. 模型输出环境评估、风险、整改建议，返回前端展示

### ⚙️ 环境依赖
- Python >=3.10
- Ollama 本地服务，提前拉取模型：`ollama pull llama3.2-vision`
- python包：`fastapi`, `uvicorn`, `pillow`, `httpx`, `chromadb`（向量检索）

### 📝 使用说明
1. 启动Ollama，保证服务可访问
2. 安装Python依赖
3. 启动FastAPI服务
4. 打开前端页面，上传环境图片，等待AI返回检测结果
